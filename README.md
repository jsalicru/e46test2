# e46test2

Test repository for a custom instrument cluster layout.

This is a clone of the E36 cluster theme from [aidac/apps](https://github.com/aidac/apps) (specifically the layout generated by `tools/gen_e36.py`).

## Layout
- `layouts/e46test2.json` — the test layout (schemaVersion 2, theme: e46test2)

It is based on the existing E36 theme which already targets the classic BMW E36 / E36 M cluster look (US MPH face with M badge, orange needles, dual scale, oil temp gauge, bottom LCD).

## Notes
- Original generator: `tools/gen_e36.py` in the upstream repo (edit that and regenerate rather than hand-editing the large JSON).
- For use with the Cluster Themes app / cluster-render on an iDrive 7 / MGU head unit.
- This is for testing only; not intended for the main apps source.

Photo reference was a high-resolution image of a US-spec E36 M cluster.
