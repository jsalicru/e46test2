# e46test2

Store-ready source for an **E46 M3** instrument cluster theme.

Add this repository as a source in the MGU Store (`jsalicru/e46test2`).  
Install **Cluster Themes**.  
Select **E46 M3** in the theme list.

The layout is drawn after the reference render in `design/e46m3-reference.png`: a 0–180 MPH speedometer with a 20–300 km/h inner ring and the /M badge, a 0–9 rev counter with the yellow pre-warning band and red zone from 7,500 rpm, the oil temperature gauge (120–300 °F) at its foot, fuel and coolant gauges, chrome rings, peach print, orange needles and the orange LCD between the dials (range, trip, outside temperature). It covers the cluster so only that theme is visible.

## Structure
- `apps/cluster_themes/` — the app
- `apps/cluster_themes/hud/layouts/e46test2.json` — the E46 M3 layout, generated by `tools/gen_e46.py` (edit that, then run `python3 tools/gen_e46.py`)
- `tools/bake_e46_fonts.py` — the theme's fonts (`hud/fonts/e4_*.json`)
- `design/e46m3-reference.png` — the render the layout is drawn from
- `shared/` — rendering engine including E36/E46 widget support
- `mgu-repo.json` — Store catalog definition
